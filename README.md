# PCCS (Punch Card Creator Simulator)
PCCS - is tool that simulates creation of the 1965-1971 style punch cards for the [IBM 024](https://dn721909.ca.archive.org/0/items/bitsavers_ibmpunched24052032426CardPunchReferenceManualOct19_6161673/A24-0520-3_24_26_Card_Punch_Reference_Manual_Oct1965.pdf).

## Requirements:
* g++
* make
* libncurses-dev

## Installation:
Enter project directory and run `make`.
